This is the main directory of the project.

Most of the files here are generated through CubeMX when configuring a project.

The `./MyDrivers` contains the drivers being used. The RTC ones I've written and are not done. The EPD ones are from the manufacturer but need to be rewritten since they used deprecated calls and are messy.

`./Src/main.c` Is where the main code lives, including the main loop.
