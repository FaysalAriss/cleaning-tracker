I did:
```
HAL_StatusTypeDef RTC_set_register_pointer(I2C_HandleTypeDef *hi2c, uint8_t register_number){
  return HAL_I2C_Master_Transmit(hi2c, DS3231_ADDRESS, &register_number, 1, HAL_MAX_DELAY);
} 
```
This works because the function is blocking so we know the state of the stack won't change. register_number is stored on the stack and we are pointing to it.
