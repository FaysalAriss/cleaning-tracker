This directory contains all the CubeIDE projects made in the journey of this project.

They are either for the prototype, testing or learning.

blackpill refers to the STM32 board commonly referred to as [blackpill](https://stm32world.com/wiki/Black_Pill)

u0 refers to the stm32u0 line



u0-RTC: shutdown and wake using RTC for interrupt

u0-EPD: project mainly using manufacturer provided code for EPD, modified just enough to work

u0-EPD-new: pin config and I code I made to work with the EPD
